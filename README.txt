САЙТ ALINA BALDAN — статика, готовая к выкладке
=============================================================

ФАЙЛЫ
  index.html    — главная страница (свадебная)
  pro.html      — страница для специалистов и организаторов
  privacy.html  — политика конфиденциальности
  assets/       — все медиа (видео, картинки, логотип, OG-картинка)

ВЫКЛАДКА
  Это статика: сервер не нужен. Достаточно положить все файлы
  в корень сайта (web root), сохранив структуру — страницы
  ссылаются на assets/ относительными путями.
  Домен: alinabaldan.ru (куплен на reg.ru).

  Варианты хостинга:
   - reg.ru hosting (там же, где домен)
   - Cloudflare Pages / GitHub Pages / Netlify — бесплатно,
     в DNS reg.ru прописать CNAME на выданный ими адрес

  После выкладки проверить:
   - https://alinabaldan.ru открывается, видео первого экрана играет
   - https://alinabaldan.ru/pro.html открывается
   - https://alinabaldan.ru/?e=corp показывает тёмный
     корпоративный первый экран
   - https://alinabaldan.ru/privacy.html открывается
   - кнопки ведут в t.me/alina_baldan с готовым сообщением

DNS (в личном кабинете reg.ru)
   - Вариант reg.ru hosting: NS уже стоят reg.ru — просто привязать
     сайт к домену в панели хостинга.
   - Вариант внешний хостинг: заменить NS на серверы хостинга
     или добавить CNAME/A-запись по инструкции хостинга.
   - HTTPS: включить бесплатный SSL (Let's Encrypt) в панели.

ЧТО ЕЩЁ ПРЕДСТОИТ (не блокирует выкладку)
   - assets/portrait.jpg — портрет Алины, место размечено в index.html

   - Яндекс.Метрика: вставить счётчик перед </body> в index.html
   - Сезонная строка в первом экране — менять текст раз в сезон
